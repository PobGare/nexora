# NEXORA

NEXORA is a responsive e-commerce product store with live search, category filtering, price sorting, product details, cart functionality, and a demo checkout experience.

## Features

- Live product search
- Category filtering
- Price sorting
- Product detail modal
- Shopping cart
- LocalStorage cart persistence
- Demo checkout flow
- Responsive product grid
- Mobile-friendly interface

## Built With

- HTML
- CSS
- JavaScript
- LocalStorage
